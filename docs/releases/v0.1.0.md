# HookBuoy v0.1.0

First public source release of HookBuoy, a small local-first CLI for testing Circle Wallets-style webhook signature verification and repeat delivery.

## Included

- `keygen`: generate a dedicated local P-256 test key pair; never overwrite an existing pair.
- `send`: render and sign synthetic `transactions.inbound` notifications with `COMPLETE` or `FAILED` states and deliver to an HTTP loopback handler.
- `--save`: persist the original signed request body bytes and three explicit headers before attempting delivery.
- `replay`: send the same saved bytes and signature sequentially, without re-signing, changing identifiers or retrying implicitly.
- HTTP status/latency observations, exact status expectations, explicit exit codes, and loopback-only delivery.
- 13 automated tests and CI on Node.js 22 and 24, including an installed npm-tarball smoke test.
- A reproducibility guide for an isolated pilot with the pinned Circle Arc Commerce example.

## Install from source

Requires Node.js 22+, npm and Git:

```sh
git clone https://github.com/NothernZhongKui/hookbuoy.git
cd hookbuoy
npm ci
npm run build
node dist/src/cli.js --help
```

Follow the [README](../../README.md#quickstart) for a local signed `send` and exact `replay`.

## Scope and limitations

- HookBuoy is **independent of Circle** and does **not** sign with Circle-managed private keys. Receivers must explicitly trust a local test public key in an isolated test environment; do not deploy this test trust path.
- Fixtures are synthetic Circle Wallets-shaped templates, not an official or exhaustive Circle event schema.
- HTTP 2xx means the delivery was accepted at the HTTP layer; it does not establish settlement, ledger correctness, or exactly-once business processing.
- The external Arc Commerce pilot provided evidence of signature verification and event persistence; the final settlement/replay machine-readable verification log was not retained.
- This is the first **GitHub source release**. The npm package is prepared and smoke-tested, but **has not been published to npm**.
