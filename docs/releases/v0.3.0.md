# HookBuoy v0.3.0

Small feature release: synthetic Circle Gateway notifications with the same local signing and byte-exact replay engine as Circle Wallets.

## Changes

- Added `gateway.deposit.finalized` synthetic fixture following the payload consumed by pinned Arc Fintech.
- Added `init arc-fintech` loopback preset and Gateway send in the interactive CLI menu.
- Added `--event-id`, `--wallet-address`, `--domain` and `--amount`, with input validation.
- `--fault signature` and `--fault body` also work for Gateway sends; saved replay remains byte-exact.
- The bundled development receiver handles Gateway notifications. Installed npm tarball smoke covers Gateway delivery and rejection.
- Refined onboarding, CLI help, compatibility guide and release notes.

## External integration

A [pinned local Arc Fintech E2E](../pilots/arc-fintech-gateway-v0.3-actions.md) passed GitHub Actions (2026-11-05): invalid signature and tampered signed body returned HTTP 403, a valid Gateway fixture returned 200 and changed a seeded transaction from PENDING to COMPLETE, and three exact replays created no additional events or side effects. This verifies a **synthetic local integration only**, not Circle-origin authentication, live deposits or on-chain settlement.

## Install

Requires Node.js 22+:

```sh
npm install --global hookbuoy@0.3.0
hookbuoy --version
hookbuoy events
```

See the [README](../../README.md), [CLI guide](../cli.md), and [Gateway guide](../gateway-preview.md).

## Scope

No additional runtime dependencies, Circle credentials, remote destinations, live transactions or production trust. The local test public key must be explicitly trusted by a receiver only in isolated development.
