# HookBuoy v0.2.1

Maintenance release focused on npm onboarding and the Trusted Publishing pipeline.

The v0.2.1 npm publication completed with provenance. The maintainer subsequently confirmed the npm package.

## Changes

- npm installation is the main onboarding path.
- `hookbuoy --version`, `-V`, and `version` report the installed CLI version.
- Added a CLI regression test for version reporting, and package smoke-test coverage of the version from the installed npm tarball.
- Updated the publishing guide to document successful `v0.2.0` manual bootstrap and the configured GitHub Actions Trusted Publisher.

No change to webhook fixture shape, signing behavior, replay byte preservation, destination restrictions or package runtime dependencies.

## Installation

Requires Node.js 22+:

```sh
npm install --global hookbuoy@0.2.1
hookbuoy --version
hookbuoy --help
```

The [publication workflow](../../.github/workflows/npm-publish.yml) reported successful submission with provenance. See [npm publishing](../npm-publishing.md) for the publication workflow.

## Scope

All requests are local, synthetic, and signed with a **local test key** (not Circle). The earlier [Arc Commerce E2E local pilot](../pilots/arc-commerce-v0.2-local.md) was conducted on `v0.2.0-dev.2` and is not a new network/on-chain pilot for `v0.2.1`.
